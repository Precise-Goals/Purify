# T-0006 — Full Pipeline Orchestration & API Route Handlers
Backlog ref: T-0006 · Sprint: 1 · Priority: MUST

## Intent
Integrate the air quality, Gemini AI, catalog validation, and deterministic impact modules into an end-to-end server-side execution pipeline (`src/lib/pipeline.ts`) with performance telemetry trace and Next.js App Router endpoints (`/api/plan` and `/api/health`).

## Scope / Out of scope
- **Scope**:
  - `src/lib/pipeline.ts`: Pipeline orchestrator with stage timings (`trace`), combining AQI fetch, Gemini generation, catalog validation, and impact model into `{ air, plan, impact, trace }`.
  - `src/app/api/plan/route.ts`: POST endpoint enforcing rate limit, key check, size cap, and pipeline execution.
  - `src/app/api/health/route.ts`: GET endpoint returning 200 OK for Docker/Cloud Run container healthchecks.
- **Out of scope**: React UI form (T-0007).
