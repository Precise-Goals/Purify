# T-0005 — Gemini AI Prompt Builder & Response Validator (`src/lib/gemini.ts`)
Backlog ref: T-0005 · Sprint: 1 · Priority: MUST

## Intent
Construct the system instructions and structured JSON prompt for Gemini AI, manage HTTP calls to Google Generative Language API without heavy SDKs, handle markdown fence stripping, retry 5xx once, handle 429 quota without retry storms, and validate returned action plans.

## Scope / Out of scope
- **Scope**:
  - `src/lib/gemini.ts`: Plain `fetch` client to `https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-flash:generateContent?key={KEY}` with structured JSON schema request.
  - Untrusted household data isolation (`<household>` declaration).
  - Markdown fence stripper (````json ... ````).
  - Quota 429 (`QUOTA`), 5xx retry logic (1 retry), model blocked (`MODEL_BLOCKED`), bad JSON (`MODEL_BAD_JSON`).
  - Injected `fetchFn` for hermetic testing.
- **Out of scope**: Full pipeline orchestration (T-0006).

## Requirements
- REQ-003: Structured JSON plan from Gemini.
- REQ-008: BYO key never logged.

## Acceptance
- AC-003-a: Returns validated action IDs from Gemini response.
- AC-003-b: 5xx retry with one attempt; failure returns code `GEMINI_FAIL`.
- AC-007-b: 429 triggers `QUOTA` code without retry storm.
