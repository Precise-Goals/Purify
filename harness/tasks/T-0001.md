# T-0001 — Curated Action Catalog (`src/lib/catalog.ts`)
Backlog ref: T-0001 · Sprint: 1 · Priority: MUST

## Intent
Provide the single source of truth for all air-quality interventions, their PM2.5 efficiencies, estimated costs, applicability scopes (indoor/outdoor/cooking/commute), and descriptive metadata. The Gemini AI model will be constrained to return action IDs from this catalog, and arithmetic impact modeling will deterministically reference these efficiency numbers.

## Scope / Out of scope
- **Scope**: Catalog data structures, TypeScript types, action catalog array with validated efficiencies, scopes, tags, and lookup helper functions (`getActionById`, `listActions`, `validateActionIds`).
- **Out of scope**: Calculating compound impact (handled in T-0002 `impact.ts`), fetching live air quality, calling Gemini API.

## Guidance
- Every action must have an id (e.g. `n95_mask_commute`, `diy_box_fan_filter`, `hepa_purifier_bedroom`, `wet_mopping_daily`, `seal_windows_weatherstrip`, `stagger_outdoor_exercise`, `switch_clean_fuel`).
- Efficiency must be between 0.0 and 1.0 (e.g., N95 outdoors ~0.60 after fit loss, HEPA ~0.50, DIY box fan ~0.40).
- Pure TypeScript, zero external runtime dependencies, 100% deterministic.

## Requirements
- REQ-004: Every AI-suggested action is validated against the curated catalog (`src/lib/catalog.ts`); unknown IDs are dropped.

## Acceptance
- AC-004-a: Given Gemini returns unknown action IDs, When validated, Then those IDs are dropped; if none remain, error code `MODEL_EMPTY` is returned.

## Risks / Notes
- Efficiency numbers must match values documented in `docs/raw.md §6` and `docs/harness.md §9`.
