# T-0007 — UI: Household Entry Form & Deterministic Impact Display
Backlog ref: T-0007 · Sprint: 1 · Priority: MUST

## Intent
Deliver the user-facing web interface for BreatheWise: location and household profile input form, BYO Gemini API key management (memory vs localStorage), real-time validation, plan generation, and clear visualization of ambient AQI, AI advice, selected catalog actions, and deterministic health impact.

## Scope / Out of scope
- **Scope**:
  - `src/app/layout.tsx`: Root HTML layout, font setup, meta tags.
  - `src/app/globals.css`: Brand design system (Orange #FF6A13, Cobalt #0047AB, Deep Cobalt #00245E).
  - `src/components/AqiBadge.tsx`: Displays AQI number, color-coded level, PM2.5 concentration, and severe hazard emergency banner.
  - `src/components/ImpactCard.tsx`: Displays exposure reduction %, cigarette equivalents avoided per day/year, and medical disclaimer caveat.
  - `src/components/PlanDisplay.tsx`: Displays AI routine tips and catalog interventions with efficiency badges.
  - `src/app/page.tsx`: Complete responsive form (city or GPS auto-locate, home type, budget, outdoor hours, purifier, notes, API key) with loading states and error banners.
- **Out of scope**: Firebase Firestore plan history (Sprint 2, T-0009).
