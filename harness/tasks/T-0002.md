# T-0002 — Deterministic PM2.5 Impact Model (`src/lib/impact.ts`)
Backlog ref: T-0002 · Sprint: 1 · Priority: MUST

## Intent
Compute exposure reduction, cigarette-equivalents avoided, and estimated CO2 reduction using deterministic arithmetic formulas. Prevent any LLM hallucination of health impact numbers.

## Scope / Out of scope
- **Scope**: Pure TypeScript impact calculator in `src/lib/impact.ts`. Computes baseline PM2.5 exposure (indoor + outdoor time weighting), mitigated exposure with multiplicative stacking, 90% max benefit cap, cigarette equivalents (22 ug/m3 = 1 cigarette/day), and caveat string.
- **Out of scope**: UI presentation (T-0007), prompt generation.

## Guidance
- Follow formulas in `docs/raw.md §6` and `docs/harness.md §5`.
- Zero PM2.5 must return 0% reduction with no `NaN` or divide-by-zero errors.
- Outdoor hours clamped to `[0, 16]`.

## Requirements
- REQ-005: Deterministic impact model computes PM2.5 reduction %, cigarette-equivalents, CO2 saved.

## Acceptance
- AC-005-a: Given a plan with N95 outdoor action, When impact is computed, Then PM2.5 reduction is 60% × (outdoorHours/24) with no double-counting.
- AC-005-b: Given zero PM2.5, When impact is computed, Then reduction is 0% and no divide-by-zero error occurs.
- AC-005-c: Given multiple same-scope actions, When impact is computed, Then total benefit is capped at 90%.
